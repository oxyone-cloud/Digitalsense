# 💡 Digital Sense – IoT & Data Monitoring

**DigitalSense** is a smart innovation platform offering digital solutions for data management, IoT, and AI integration. Developed by **SSCI Solution of Cold**, this Flutter-based solution monitors and analyzes data from industrial refrigeration systems to optimize performance and automate processes.

🌐 **Live Application:** [https://digitalsense-5a6f2.web.app](https://digitalsense-5a6f2.web.app)

---

## 🚀 Features
* Real-time monitoring of temperature and refrigeration system performance.
* Bluetooth-based sensor connectivity.
* Cloud data storage and analytics via **Firebase**.
* Interactive dashboards and alert notifications.
* Compatible with the **SSCIAPPBluetooth** ecosystem.
* Built entirely with **Flutter** for web and mobile devices.

---

## 🧰 Technologies Used
* **Flutter**
* **Firebase** (Firestore, Hosting)
* **Bluetooth Low Energy (BLE)**
* **Dart Language**
* **Cloud Firestore Database**
